# Block 2 - API Composition

Project minh họa API Composition bằng Baseline, BFF và GraphQL.

Yêu cầu: Node.js 20 trở lên.

## 1. Tải dependency

```bash
npm install
```

## 2. Tạo seed data

```bash
npm run seed
```

## 3. Chạy project

```bash
npm start
```

Mở <http://localhost:5173/>. Nhấn `Ctrl+C` để dừng.

> Nếu PowerShell chặn `npm.ps1`, hãy dùng `npm.cmd` thay cho `npm`.
